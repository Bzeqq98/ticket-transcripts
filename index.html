🎫 Ticket Transcript System

Hier kannst du die Transcripts deiner Discord Tickets einsehen

📋 So funktioniert's:

1. Im Discord Bot "Transcript erstellen" auswählen

2. Link kopieren und hier einfügen

3. Transcript wird automatisch angezeigt

🔍 Transcript anzeigen

Gebe eine Transcript ID ein und klicke auf "Transcript laden"

ℹ️ Informationen

URL Format: https://bzeqq98.github.io/ticket-transcripts/?id=DEINE_ID

Speicherdauer: Transcripts sind 30 Tage verfügbar

Support: Bei Problemen den Discord Server kontaktieren
